# Счетный двор - Обучающий математический сервис

Веб-приложение для обучения математике учеников начальных классов с прогрессивной системой сложности и геймификацией.

## 🎯 Возможности

### Обучение
- **12 тем** с прогрессивной сложностью (от сложения до 10 до смешанных операций)
- **10 примеров** на каждый урок
- Мгновенная проверка ответов
- Система оценок (⭐⭐⭐ за идеальный результат)

### Геймификация
- **Система уровней** (1-50) с опытом (XP)
- **10 достижений** за различные успехи
- **Доска лидеров** топ-10 игроков
- Персонализация с выбором аватара

### Статистика
- Процент правильных ответов
- История пройденных уроков
- График прогресса по дням
- Детальная статистика по темам

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- npm или yarn

### Установка

1. **Клонируйте репозиторий**
```bash
cd /Users/sergey_verbin/CascadeProjects/math-kids
```

2. **Установите зависимости для backend**
```bash
cd backend
npm install
```

3. **Установите зависимости для frontend**
```bash
cd ../frontend
npm install
```

### Запуск

1. **Запустите backend** (в одном терминале)
```bash
cd backend
npm start
```
Сервер запустится на http://localhost:3001

2. **Запустите frontend** (в другом терминале)
```bash
cd frontend
npm run dev
```
Приложение откроется на http://localhost:5173

## 🛠 Технологии

### Backend
- **Node.js** + **Express** - сервер
- **SQLite** - база данных
- **JWT** - авторизация
- **bcryptjs** - хеширование паролей

### Frontend
- **React 19** - UI библиотека
- **Vite** - сборщик
- **React Router** - роутинг
- **TailwindCSS** - стилизация
- **Lucide React** - иконки
- **Axios** - HTTP клиент

## 📊 API Endpoints

### Авторизация
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход

### Пользователь
- `GET /api/user/profile` - Профиль пользователя
- `PUT /api/user/avatar` - Обновить аватар

### Темы
- `GET /api/topics` - Список всех тем
- `GET /api/topics/:id` - Информация о теме

### Уроки
- `POST /api/lessons/start` - Начать урок
- `POST /api/lessons/submit` - Отправить результаты
- `GET /api/lessons/leaderboard` - Доска лидеров
- `GET /api/lessons/achievements` - Достижения

## 🎮 Как играть

1. **Регистрация** - Создай аккаунт, выбери аватар
2. **Выбери тему** - Начни с простого сложения
3. **Реши примеры** - 10 примеров на урок
4. **Получи награды** - XP, уровни, достижения
5. **Соревнуйся** - Попади в топ-10 лидеров!
