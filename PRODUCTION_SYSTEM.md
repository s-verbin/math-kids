# 🥚 Система производства ресурсов

## Обзор

Система позволяет животным производить ресурсы (яйца, молоко, шерсть), которые игрок может собирать за монеты.

---

## 🏗️ Архитектура

### Backend

#### Новые таблицы БД:
```sql
animal_production (
  id, user_animal_id, resource_type, ready_at, collected
)

user_resources (
  id, user_id, resource_type, quantity, last_collected
)
```

#### API endpoints:
- `GET /api/production/status` — статус производства всех животных
- `POST /api/production/collect` — собрать готовый ресурс
- `GET /api/production/resources` — инвентарь ресурсов пользователя

#### Контроллер:
`backend/src/controllers/productionController.js`

### Frontend

#### Новые компоненты:
- `Resource.jsx` — 3D модели ресурсов (яйцо, молоко, шерсть)
- `ProductionIndicator.jsx` — индикатор над животным
- `ResourcesManager.jsx` — контейнер для управления ресурсами

#### Хуки:
- `useAnimalProduction.js` — логика производства ресурсов
- `useAnimalMovement.js` — логика движения (вынесена из ProceduralAnimal)

#### Система событий:
`services/EventBus.js` — pub/sub для событий фермы

## 💡 Бонусы производства

### Множители скорости:
- **Счастье ≥ 80%** → +20% скорость
- **Сытость ≥ 80%** → +10% скорость
- **Итого:** до +30% скорость производства

### Формула:
```javascript
adjustedTime = baseTime / (1 + happinessBonus + hungerBonus)
```

## 🎮 Механика

### 1. Производство
- Животное автоматически начинает производить ресурс
- Таймер отсчитывает время до готовности
- Индикатор показывает оставшееся время

### 2. Готовность
- Когда ресурс готов, индикатор становится зелёным
- Появляется 3D модель ресурса рядом с животным
- Анимация пульсации привлекает внимание

### 3. Сбор
- Клик на индикатор или животное собирает ресурс
- +монеты в кошелёк
- +1 ресурс в инвентарь
- Запускается новый цикл производства

## 📡 События (EventBus)

### Типы событий:

#### Animal events:
- `ANIMAL_FED` — животное покормили
- `ANIMAL_PETTED` — животное погладили
- `ANIMAL_PURCHASED` — животное куплено
- `ANIMAL_SOLD` — животное продано

#### Resource events:
- `RESOURCE_PRODUCED` — ресурс произведён
- `RESOURCE_COLLECTED` — ресурс собран
- `RESOURCE_READY` — ресурс готов к сбору

#### Farm events:
- `ITEM_PURCHASED` — предмет куплен
- `POOP_CREATED` — какашка создана
- `POOP_CLEANED` — какашка убрана

### Использование:

```javascript
import eventBus, { EVENTS } from './services/EventBus';

// Подписка
eventBus.on(EVENTS.RESOURCE_COLLECTED, (data) => {
  console.log('Собран ресурс:', data);
});

// Эмит
eventBus.emit(EVENTS.RESOURCE_COLLECTED, {
  type: 'egg',
  value: 5,
  animalId: 123
});
```
