# Инструкция по исправлению ошибки 401

## Проблема
После авторизации все API запросы возвращают 401 Unauthorized.

## Решение

### Вариант 1: Очистить localStorage в браузере

1. Открой DevTools (F12 или Cmd+Option+I)
2. Перейди на вкладку **Console**
3. Выполни команду:
```javascript
localStorage.clear()
```
4. Обнови страницу (F5 или Cmd+R)
5. Зарегистрируйся заново

### Вариант 2: Через Application/Storage

1. Открой DevTools (F12)
2. Перейди на вкладку **Application** (или **Storage** в Firefox)
3. В левом меню найди **Local Storage** → `http://localhost:5173`
4. Удали ключ `token` или очисти всё
5. Обнови страницу
6. Зарегистрируйся заново

### Вариант 3: Режим инкогнито

1. Открой новое окно в режиме инкогнито (Cmd+Shift+N или Ctrl+Shift+N)
2. Перейди на `http://localhost:5173`
3. Зарегистрируйся

## Почему это происходит?

Мы несколько раз удаляли базу данных (`mathkids.db`), но токен в localStorage браузера остался. Этот токен указывает на несуществующего пользователя, поэтому backend возвращает 401.

## Проверка что токен работает

После регистрации/входа открой Console и выполни:
```javascript
localStorage.getItem('token')
```

Должна вернуться длинная строка (JWT токен). Если `null` - токен не сохранился.
